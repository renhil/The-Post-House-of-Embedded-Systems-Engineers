POST HOUSE

关于这座驿站

仓库名叫 The Post House of Embedded Systems Engineers。网站把它收成深圳硬件人能隔三差五打开的柜台：题、段子、工具、速查，再加上一份不肯编造的本地备忘。第一阶段想先见到 1000 位过客。

人数怎么数

页面底部（首页在柜台卡片上）用不蒜子数访问。不用注册，脚本从 busuanzi.ibruce.info 加载，国内一般开得了。它是第三方，能看到这次访问，本站自己不建账号、不存表单。

本站使用百度统计做匿名访问统计。本地预览不加载这段脚本，避免把调试访问算进去。

计数暂时连不上时，题和工具照常可用。过客数对应不蒜子的 site uv，翻阅数对应 site pv。目标看的是过客。

什么该写进来，什么别写

  • 题目、段子、公式和采购方法，写清楚适用边界就行。
  • 活动必须是核实过的。假例子只放在 examples 里。
  • 档口必须带 asOf 和 source，并且 example 为 false。不要写价格。
  • 不要把某一家公司的内部面试题当成「真题泄露」贴上来。

改哪里

  • data/questions.json 题库。同一天的题目由本地日期对题库长度取模决定，起点是 2026-01-01。
  • data/jokes.json 段子，算法和题目一样。
  • data/events.json 告示板。
  • data/markets.json 华强北的区域和档口。
  • data/books.json 驿站书房。只加原文已进入公有领域的书。构建时会生成每本书的页面。
  • assets/calc.js 计算器。改完跑 npm run check。

本地预览

需要 Node 20 以上。不要直接双击 html，浏览器会拦住页面去读 json。

npm run preview

然后打开 http://127.0.0.1:4173。构建产物在 dist/，这个目录不进 git。上线时由 GitHub Actions 再构建一次。
